# Atelier Coffee

A fictional specialty coffee brand website created as a portfolio case study. Built with Next.js, TypeScript, and Tailwind CSS.

## Important project note

Atelier Coffee is not a real client or operating café. Names, products, prices, and brand language are original fictional content. All visual artwork is original SVG/CSS created for this project; there are no third-party stock assets or implied client claims. The contact form is explicitly presented as a demo and never transmits or stores data.

## Run locally

Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run build
```

## Deploy to Vercel

### GitHub workflow

1. Create a new empty GitHub repository named `atelier-coffee` (do not reuse `purchase-record`).
2. From this folder, initialize Git, commit the project, and push it to the new repository.
3. In Vercel, choose **Add New → Project**, import the new GitHub repository, and keep the detected Next.js defaults.
4. Deploy. No environment variables are required.

### Vercel CLI

```bash
npx vercel
```

Run the command from this project folder and follow the prompts. Use `npx vercel --prod` when ready to promote a production deployment.

## Contra project description

**Title:** Atelier Coffee — Specialty Coffee Brand & Responsive Website

**Short summary:** A fictional specialty coffee brand translated into a warm, editorial, mobile-first web experience.

**Full description:**

Atelier Coffee is a self-initiated brand and web design concept for a fictional specialty café. I shaped the project from positioning and verbal identity through art direction, interface design, and front-end development.

The experience pairs expressive editorial typography with a restrained palette, original geometric illustrations, and clear interaction patterns. Four responsive pages introduce the brand story, seasonal menu, and contact journey, with an intentionally transparent demo state for the non-functional enquiry form.

Built with Next.js, TypeScript, and Tailwind CSS, the site is designed for fast loading, accessible navigation, reduced-motion preferences, and consistent behavior across desktop and mobile screens.
